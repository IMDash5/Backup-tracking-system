# Система учёта резервных копий

Консольное приложение для учёта серверов и их резервных копий.

## Возможности

- просмотр и поиск серверов;
- проверка доступного места для резервной копии;
- создание резервных копий с проверкой дублирования на дату;
- отмена резервных копий;
- просмотр списка резервных копий;
- статистика по резервным копиям сервера (количество, суммарный объём, актуальность);
- сортировка серверов по объёму хранилища;
- отбор серверов по минимальному объёму хранилища;
- добавление новых серверов.

## Структура проекта

- `main.py` — точка запуска и меню приложения;
- `servers.py` — работа с серверами;
- `backups.py` — работа с резервными копиями;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции ввода;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Формат хранения данных

Серверы (`data/servers.json`) — список словарей с полями `id`, `name`, `storage_capacity`.

Резервные копии (`data/backups.json`) — список словарей с полями `id`, `server_id`, `backup_date`, `size`.
