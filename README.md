# Система учёта резервных копий

## Назначение

Консольное приложение для учёта серверов и их резервных копий.

Приложение позволяет:

- просматривать серверы;
- находить серверы по названию;
- проверять свободное место на сервере;
- проверять доступность сервера на определённую дату;
- создавать резервные копии;
- отменять резервные копии;
- просматривать список резервных копий;
- добавлять новые серверы;
- сортировать серверы по объёму хранилища;
- отбирать серверы по минимальному объёму хранилища;
- добавлять операторов и просматривать их список;
- хранить данные между запусками приложения.

## Целевая аудитория

Системные администраторы и IT-специалисты, которым необходимо вести
учёт серверов и контролировать создание резервных копий.

## Предметная область

Основными объектами предметной области являются:

- сервер;
- оператор;
- резервная копия.

Оператор может создавать резервные копии серверов на определённые
даты. Один сервер не может иметь две активные резервные копии на одну
и ту же дату. Отменённая резервная копия не блокирует сервер и
позволяет создать новую резервную копию на эту дату.

## Основные сущности

### Server — сервер

Объект `Server` представляет сервер, для которого ведётся учёт
резервных копий.

Основные атрибуты:

- `id` — уникальный идентификатор сервера;
- `name` — название сервера;
- `storage_capacity` — объём хранилища сервера.

Основные методы:

- `has_free_space()` — проверка достаточности места для копии нужного
  размера;
- `__str__()` — строковое представление сервера.

### Operator — оператор

Объект `Operator` представляет оператора, создающего и отменяющего
резервные копии.

Основные атрибуты:

- `id` — уникальный идентификатор оператора;
- `name` — имя оператора;
- `email` — адрес электронной почты.

Основные методы:

- `__str__()` — строковое представление оператора;
- `from_data()` — создание объекта `Operator` из набора данных.

### Backup — резервная копия

Объект `Backup` представляет резервную копию сервера, созданную
оператором.

Основные атрибуты:

- `id` — уникальный идентификатор резервной копии;
- `server` — объект `Server`;
- `backup_date` — дата резервной копии;
- `size` — размер резервной копии;
- `operator` — объект `Operator`;
- `is_cancelled` — признак отмены резервной копии.

Основные методы:

- `cancel()` — отмена резервной копии;
- `__str__()` — строковое представление резервной копии.

## Основные операции

### Работа с серверами

- добавление сервера;
- поиск сервера по названию;
- проверка свободного места;
- отбор серверов по объёму хранилища;
- сортировка серверов;
- просмотр списка серверов.

### Работа с операторами

- добавление оператора;
- просмотр списка операторов.

### Работа с резервными копиями

- создание резервной копии;
- проверка доступности сервера на дату;
- отмена резервной копии;
- просмотр списка резервных копий;
- просмотр статистики по резервным копиям сервера.

При создании резервной копии проверяется наличие другой активной
резервной копии этого же сервера на ту же дату.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

- `data/servers.json`;
- `data/operators.json`;
- `data/backups.json`.

При загрузке данные из JSON преобразуются в объекты `Server`,
`Operator` и `Backup`. При сохранении объекты преобразуются обратно в
данные JSON. Для связи резервной копии с сервером и оператором в
`backups.json` используются их идентификаторы `server_id` и
`operator_id`.

## Назначение модулей

### `main.py`

Точка входа в приложение.

Отвечает за:

- запуск приложения;
- отображение меню;
- получение данных от пользователя;
- организацию пользовательских сценариев.

### `models/servers.py`

Содержит класс `Server` и функции работы с серверами.

### `models/operators.py`

Содержит класс `Operator` и функции работы с операторами.

### `models/backups.py`

Содержит класс `Backup` и функции работы с резервными копиями.

### `storage.py`

Отвечает за загрузку и сохранение данных.

Выполняет преобразование:

- JSON → объекты Python;
- объекты Python → JSON.

### `utils.py`

Содержит вспомогательные функции:

- `input_int()` — безопасный ввод целого числа;
- `input_float()` — безопасный ввод дробного числа;
- `input_date()` — безопасный ввод даты.

### `tests/`

Содержит автоматизированные тесты проекта.

## Запуск приложения

Для запуска приложения выполнить:

```text
python main.py
```

После запуска отобразится главное меню.

## Тестирование

Для запуска автоматизированных тестов выполнить:

```text
pytest -v
```

Тесты проверяют:

- создание и работу объектов `Server`, `Operator` и `Backup`;
- методы классов;
- операции с серверами;
- создание и отмену резервных копий;
- связь резервной копии с сервером и оператором;
- правила доступности сервера на дату.
