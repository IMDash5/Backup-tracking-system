# Система учета резервных копий


Система учета и контроля резервных копий.

## Назначение


Приложение предназначено для учета резервных копий данных и контроля их состояния. Система позволяет хранить информацию о сервере, дате создания резервной копии и её размере, а также проверять наличие, актуальность и возможность хранения резервной копии.

## Целевая аудитория


* Системные администраторы
* IT-специалисты
* Владельцы небольших организаций
* Сотрудники, ответственные за сохранность данных

## Предметная область

Система предназначена для учета резервных копий данных с учетом сервера, даты создания копии, её размера и доступного места для хранения. Приложение позволяет определить, доступна ли резервная копия, достаточно ли места для её хранения и является ли копия актуальной.

## Основные сущности


* Сервер
* Резервная копия
* Хранилище
* Пользователь

## Основные функции


* Проверка наличия резервной копии
* Проверка доступного места для хранения резервной копии
* Проверка актуальности резервной копии
* Учет даты создания резервной копии
* Учет размера резервной копии

## План развития


На следующих этапах планируется:

* разработка веб-приложения;
* подключение базы данных;
* реализация пользователей и ролей;
* добавление автоматического создания резервных копий;
* разработка API;
* настройка уведомлений об устаревших резервных копиях;
* контейнеризация приложения;
* настройка CI/CD.
